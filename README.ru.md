## Зачем

В macOS фокус между мониторами зависит от клика: курсор может быть на мониторе B, а ввод всё ещё идёт в окно на мониторе A.

FocusFlow мыслит мониторами, а не окнами: как только курсор переходит на другой монитор, активируется последнее использованное там окно. Внутри одного монитора ничего не происходит.

## Возможности

- **Активация при переходе между мониторами**
- **Значок в строке меню по реальному расположению**, текущий монитор подсвечен синим
- **12 языков**, переключение в меню
- **Запуск при входе**
- **Лёгкий**: никаких пробуждений, пока мышь неподвижна

## Установка

1. Скачайте DMG из [Releases](https://github.com/to-explore-future/focusflow/releases)
2. Перетащите в «Программы»
3. Первый запуск: правый клик → **Открыть** (без нотаризации)
4. Разрешите **универсальный доступ**

macOS 12 или новее.

## Частые вопросы

**Первый запуск заблокирован?** Приложение не нотаризовано: правый клик → Открыть.

**Зачем универсальный доступ?** Без него нельзя активировать окна других приложений.

**Сколько мониторов?** Любое количество. Значок следует реальному расположению.
