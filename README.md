## 为什么需要它

macOS 的多屏焦点是「点击驱动」的：光标在 B 屏，键盘输入还发在 A 屏的窗口。

FocusFlow 按「屏幕」而不是「窗口」来思考——光标跨到哪块屏，那块屏上你最后用的窗口就回到前台。同屏内移动鼠标不会有任何动作，不会误切窗口。

## 功能

- **跨屏激活**：记住每块屏上最后用的窗口，光标跨过去就激活它
- **菜单栏图标跟你的摆放走**：按真实排列绘制，当前屏蓝色高亮
- **12 种语言**：菜单里随时切换，默认跟随系统
- **开机自启动**
- **轻量**：鼠标不动时不产生任何唤醒

## 安装

1. 到 [Releases](https://github.com/to-explore-future/focusflow/releases) 下载 DMG
2. 把 FocusFlow 拖进「应用程序」
3. 首次打开：右键 → **打开**（未公证，系统会提示一次）
4. 按提示授予 **辅助功能** 权限

系统要求：macOS 12 或更高。

## 常见问题

**第一次打开被系统拦了？**
未做 Apple 公证，右键 → 打开即可，只需一次。

**为什么要辅助功能权限？**
激活其他 App 的窗口必须用它，没有别的办法。

**某些 App 切过去没反应？**
极少数 App 会抵抗程序化激活。

**支持几块屏幕？**
任意块。菜单栏图标会按你实际的排列来画。
