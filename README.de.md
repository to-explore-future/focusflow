## Warum

Unter macOS ist der Fokus bei mehreren Bildschirmen klickgesteuert: Der Cursor kann auf Bildschirm B sein, die Tastatureingaben gehen aber weiter an ein Fenster auf Bildschirm A.

FocusFlow denkt in Bildschirmen statt in Fenstern: Sobald der Cursor auf einen anderen Bildschirm wechselt, wird das dort zuletzt benutzte Fenster wieder aktiviert. Innerhalb eines Bildschirms passiert nichts.

## Funktionen

- **Aktivierung beim Bildschirmwechsel**
- **Menüleistensymbol entspricht der echten Anordnung**, aktueller Bildschirm blau hervorgehoben
- **12 Sprachen**, im Menü umschaltbar
- **Beim Anmelden starten**
- **Leichtgewichtig**: keine Aufwachvorgänge bei ruhender Maus

## Installation

1. DMG aus den [Releases](https://github.com/to-explore-future/focusflow/releases) laden
2. In „Programme“ ziehen
3. Erster Start: Rechtsklick → **Öffnen** (nicht notarisiert)
4. **Bedienungshilfen**-Berechtigung erteilen

macOS 12 oder neuer.

## FAQ

**Erster Start blockiert?** Nicht notarisiert – Rechtsklick → Öffnen.

**Warum Bedienungshilfen?** Nur damit lassen sich Fenster anderer Apps aktivieren.

**Wie viele Bildschirme?** Beliebig viele. Das Symbol folgt der echten Anordnung.
