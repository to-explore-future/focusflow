## 왜 필요한가

macOS의 멀티 디스플레이 포커스는 클릭 기반입니다. 커서가 B 화면에 있어도 키 입력은 A 화면의 창으로 갑니다.

FocusFlow는 '창'이 아니라 '디스플레이' 단위로 생각합니다. 커서가 다른 디스플레이로 넘어가면 그 디스플레이에서 마지막으로 쓰던 창을 복원합니다. 같은 화면 안에서 마우스를 움직여도 아무 일도 일어나지 않습니다.

## 기능

- **화면을 넘을 때 복원**: 디스플레이별로 마지막 창을 기억
- **메뉴 막대 아이콘이 실제 배치대로 표시**, 현재 화면은 파란색으로 강조
- **12개 언어**: 메뉴에서 전환, 기본은 시스템 설정을 따름
- **로그인 시 실행**
- **가벼움**: 마우스가 멈춰 있으면 깨어나지 않음

## 설치

1. [Releases](https://github.com/to-explore-future/focusflow/releases)에서 DMG 다운로드
2. 응용 프로그램으로 드래그
3. 첫 실행: 오른쪽 클릭 → **열기** (공증되지 않음)
4. **손쉬운 사용** 권한 허용

macOS 12 이상.

## 자주 묻는 질문

**처음 실행이 차단됨** — 공증되지 않았습니다. 오른쪽 클릭 → 열기.

**왜 손쉬운 사용 권한이 필요한가요?** 다른 앱의 창을 앞으로 가져오려면 필요합니다.

**디스플레이는 몇 대까지?** 제한 없음. 아이콘은 실제 배치대로 그려집니다.
