## Porquê

No macOS, o foco entre ecrãs depende do clique: o cursor pode estar no ecrã B enquanto as teclas continuam a ir para uma janela do ecrã A.

O FocusFlow pensa por ecrã, não por janela: quando o cursor passa para outro ecrã, reativa a última janela usada lá. Mover o rato dentro do mesmo ecrã não faz nada.

## Funcionalidades

- **Ativação ao mudar de ecrã**
- **Ícone da barra de menus conforme a disposição real**, ecrã atual destacado a azul
- **12 idiomas**, alteráveis no menu
- **Abrir ao iniciar sessão**
- **Leve**: sem ativações com o rato parado

## Instalação

1. Descarregue o DMG dos [Releases](https://github.com/to-explore-future/focusflow/releases)
2. Arraste para Aplicações
3. Primeiro arranque: clique direito → **Abrir** (não notarizado)
4. Conceda permissão de **Acessibilidade**

macOS 12 ou superior.

## FAQ

**Bloqueado no primeiro arranque?** Não notarizado: clique direito → Abrir.

**Porque é precisa Acessibilidade?** É a única forma de ativar janelas de outras apps.

**Quantos ecrãs?** Quantos quiser. O ícone segue a disposição real.
