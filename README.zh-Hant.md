## 為什麼需要它

macOS 的多螢幕焦點是「點擊驅動」的：游標在 B 螢幕，鍵盤輸入還是送到 A 螢幕的視窗。

FocusFlow 以「螢幕」而不是「視窗」為單位——游標跨到哪塊螢幕，那塊螢幕上你最後用的視窗就會回到最前面。在同一塊螢幕內移動滑鼠不會有任何動作。

## 功能

- **跨螢幕啟用**：記住每塊螢幕最後使用的視窗
- **選單列圖示依實際排列繪製**，目前螢幕藍色高亮
- **12 種語言**：選單內切換，預設跟隨系統
- **開機自動啟動**
- **輕量**：滑鼠靜止時不產生喚醒

## 安裝

1. 從 [Releases](https://github.com/to-explore-future/focusflow/releases) 下載 DMG
2. 拖進「應用程式」
3. 首次開啟：右鍵 → **打開**（未公證）
4. 授予 **輔助使用** 權限

需要 macOS 12 以上。

## 常見問題

**第一次開啟被系統阻擋？** 未公證，右鍵 → 打開即可。

**為什麼需要輔助使用權限？** 啟用其他 App 的視窗必須用它。

**支援幾塊螢幕？** 任意數量，圖示會依實際排列繪製。
