## なぜ必要か

macOS のマルチディスプレイのフォーカスはクリック駆動です。カーソルが B の画面にあっても、キー入力は A の画面のウインドウに送られます。

FocusFlow は「ウインドウ」ではなく「ディスプレイ」単位で考えます。カーソルが別のディスプレイに移ると、そのディスプレイで最後に使ったウインドウを復元します。同じ画面内でマウスを動かしても何も起きません。

## 機能

- **画面をまたぐと復元**：ディスプレイごとに最後のウインドウを記憶
- **メニューバーのアイコンが実際の配置に対応**：現在の画面がハイライト
- **12 言語**：メニューから切り替え、既定はシステムに追従
- **ログイン時に起動**
- **軽量**：マウスが止まっている間はウェイクアップしません

## インストール

1. [Releases](https://github.com/to-explore-future/focusflow/releases) から DMG をダウンロード
2. FocusFlow を「アプリケーション」へドラッグ
3. 初回起動：右クリック → **開く**（未公証）
4. **アクセシビリティ** 権限を許可

macOS 12 以降。

## よくある質問

**初回起動がブロックされた** — 未公証です。右クリック → 開く。

**なぜアクセシビリティ権限が必要？** 他のアプリのウインドウを前面に出すために必要です。

**ディスプレイは何台まで？** 何台でも。アイコンは実際の配置に合わせて描画されます。
